# Roble Web Studio

Portfolio website for Armando Robles, a web designer based in New Brighton, Minnesota.

## Editing

- Edit page content in `src/index.html`.
- Edit colors, spacing, typography, and layout in `src/styles.css`.
- Store website images in `src/assets/`.

## Build

Install Node.js, then run:

```bash
npm run build
```

The finished static website is generated in `dist/`.
